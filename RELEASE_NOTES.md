# TaskFlow v1.0.0

TaskFlow v1.0.0 is the first desktop and web release of the TaskFlow task management system.

## Highlights

- One unified dashboard for tasks, projects, analytics, calendar, activity, notifications, profile, and settings
- Secure registration and login with private user data
- Task creation, editing, completion, deletion, search, filtering, sorting, and bulk actions
- Project detail view with progress, completed tasks, and remaining tasks
- Categories, priorities, due dates, subtasks, reminders, and recurring tasks
- Saved filters and reusable task templates
- Windows desktop installer with desktop and Start menu shortcuts

## Download and install

1. Download `TaskFlow Setup 1.0.0.exe` from the Assets section of the GitHub release.
2. Open the downloaded installer.
3. Select an installation folder and complete the setup.
4. Start TaskFlow from the desktop shortcut or Start menu.

Windows may display a SmartScreen warning because this educational release is not code-signed. Check that the installer came from the official repository before continuing.

## System requirements

- Windows 10 or Windows 11, 64-bit
- Approximately 250 MB of available storage

## Known limitations

- Data is stored locally and does not synchronize between computers.
- Notifications are shown inside TaskFlow; email and native desktop delivery are not yet available.
- Team collaboration and task assignment are not included in this release.
